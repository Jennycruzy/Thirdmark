# Canonical example-counter deployment fixture

This directory contains the Compact source and generated contract bindings from
the pinned Midnight `example-counter` commit
`273f083ab36a52407f16ec9a9796d902226e05d6`. It exists only to make the required
browser wallet smoke test reproducible before Thirdmark deployment.

The source is Apache-2.0 under the Midnight Foundation copyright notice from the
upstream repository. The generated bindings are regenerated by Compact 0.30.0 in
`scripts/verify-compact.sh`; the browser proving keys are build artifacts and are
never committed.
